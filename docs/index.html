✨ 轻启标签页 (QinStart-NewTab)

一个简洁优雅的浏览器新标签页插件，开源免费，尊重隐私，无广告。

🧪 在线演示

点击下方按钮体验新标签页的完整功能（实时时钟、每日一言、搜索框、明暗主题切换）。

🔍 打开在线演示版

※ 演示版本与浏览器插件功能一致，但背景图片等个性化设置不会保存。

📦 主要功能

  • ⏰ 实时数字时钟与日期显示
  • 🔍 必应 (Bing) 搜索引擎快捷入口
  • 📝 “一言” (Hitokoto) 随机语录展示
  • ☀️ / 🌙 亮色与暗色双主题模式，自动切换
  • 🖼️ 可为亮/暗主题分别设置自定义背景图片
  • ⚙️ 所有设置自动保存至浏览器本地存储

📥 安装插件

支持 Firefox、Chrome、Edge 浏览器。

  • 🦊 Firefox 用户：点击安装 Firefox 扩展（等待上架，或手动加载 .xpi）
  • 🐉 Chrome / Edge 用户：从 Releases 页面 下载对应 .zip，开启开发者模式后加载。

🔗 项目源码：GitHub - ZhX589/QinStart-NewTab

🛠️ 技术说明

基于 Manifest V3，使用 CSS 自定义属性实现主题切换，数据来自 hitokoto.cn 开放 API，图标使用 Font Awesome 6.5.1。
